How to use Infinity Notes

A practical walkthrough. Everything you write stays on your computer: there is no account, no sync and no network service.

Getting started

  1. Download the installer for your system and install it.
  2. Start Infinity Notes. There is nothing to sign in to. Home shows quick actions, pinned notes, recent notes and the reminders due today.
  3. Press Ctrl+N, type a title in the new tab, press Enter and keep typing the text. Notes save on their own as you write.

The window

  • Top bar: the menus File, View and Help, the search box in the middle (Ctrl+K), buttons that show or hide the notes tree and the details panel, and the window buttons. Alt opens the menus from the keyboard.
  • Rail on the left: Home, Notes, Stickies, Reminders, and Settings at the bottom.
  • Notes tree: Common, your projects and their folders, and the Trash. Toggle it with Ctrl+\.
  • Details panel: tags, links in and out, reminders and more for the open note. Toggle it with Ctrl+Shift+\.
  • Theme: View > Light, Dark or System theme.

Notes and projects

  • Notes live in Common or in a project, inside folders as deep as you like. Create them from the tree, from Home, or with Ctrl+N.
  • In the tree, arrow keys move, expand and collapse, Enter opens, F2 renames, Delete moves to the Trash and Shift+F10 opens the item menu.
  • Deleted notes go to the Trash, where you can restore them.
  • Every note keeps a version history (right-click the text > Version history) so you can go back to an earlier state.
  • A note is rich text or plain text, and can be converted either way from the note menu.

Tabs

Each note opens in its own tab; the tab is the note's title. Double-click a tab, or press F2 on it, to rename the note. Switch with Ctrl+Tab and Ctrl+Shift+Tab, close with Ctrl+W. Your tabs come back when you start the app again.

Formatting

  • Toolbar: select text and a small toolbar appears above it (Alt+F10 shows it at the cursor). It has bold, italic, links and more, plus Font, Size, Text color and Highlight.
  • Colors: pick a preset or Default, which removes the color so the text follows the light or dark theme.
  • Insert menu: type / at the start of a line or after a space for headings, lists, checklists, quotes, code, tables, images, files, note links and reminders.
  • Note menu: right-click the text (or Shift+F10) for insert, reminders, Find, Convert, Version history and Float as sticky.
  • Images: paste, drop or insert them.

Markdown and plain-text export keep the text and structure but drop fonts, sizes and colors.

Tables

  • Insert a table from the / menu or the note menu: choose the number of rows and columns and whether the first row is a header.
  • Tab and Shift+Tab move between cells. Drag a column border to resize it.
  • The Table menu adds and removes rows and columns, turns the header row on or off, and deletes the table.
  • Cells take the same formatting as the rest of the note, including fonts and colors.
  • Copy and paste work both ways: copy cells into a spreadsheet, or paste a table from a spreadsheet or a web page (or tab-separated text) to create one.

Markdown export writes tables as Markdown tables. A table can have up to 10,000 cells, and a merged cell can span up to 50 rows or columns. A larger table is refused with a message, and tab-separated text that would make one is pasted as plain text.

Files

Add a file to a note by dropping or pasting it, or from the / menu. Images are always copied. For other files Infinity Notes asks how to keep them:

  • Copy into Infinity Notes: a copy goes into your data folder. It stays available if the original is moved or deleted, and it is included in your backups.
  • Link to the original: the note points at the file where it is. Nothing is copied, so it is not in your backups, and the link stops working if you move, rename or delete the original.

Under When adding files in Settings you can choose Ask every time (the default), Always copy into Infinity Notes or Always link to the original. A linked file can be copied in later with Copy into Infinity Notes on its chip.

Files over 25 MB are never copied. Infinity Notes shows a warning and offers only a link to the original. You can lower this copy limit in Settings.

On Windows only files on a local drive can be linked. Copy files from a network location into Infinity Notes instead; network links in an imported export are not kept.

Locked notes

Lock a note that holds something private with Lock note… in the note menu, the Details panel or the command palette. Its body is encrypted on disk (AES-256-GCM). The title and any reminder titles are not encrypted and stay visible, so you can still find the note in the tree, tabs and search; search never looks inside the body.

  • A password is always required, on Windows and Linux.
  • On Windows computers where it is available you can also unlock with Windows Hello (face, fingerprint or PIN). The password stays the fallback, so a Windows reinstall never locks you out.
  • An unlocked note locks itself again after 5 idle minutes (change this in Settings), when you lock the screen (Windows) or the computer sleeps, and when you quit. Use Lock now or Lock all notes to lock at once.
  • Locked notes cannot float as stickies, reminders in them notify without showing their text, and Export all notes leaves them out. Backups contain them encrypted.

Locking cannot be taken back for what was saved before. When you lock a note, its earlier versions, drafts, search entries and other unencrypted copies are destroyed, so version history cannot bring back an unlocked copy. Backups you made before locking still contain the old text. A forgotten password cannot be recovered: there is no reset and no way to read the note without it. Keep the password somewhere safe.

Attached and linked files are not encrypted. Keep confidential files out of locked notes or protect them separately.

Stickies

  • Right-click a note's text and choose Float as sticky, or press Ctrl+Shift+N for a new one. The sticky is its own small window outside the main window.
  • Type in the sticky or in the note's tab: both show the same note as you write.
  • Drag a sticky by its header. Click its title (or press F2) to rename it. The header also shows the note's project.
  • Colors: pick one of the presets or a custom color (any color, with a color picker or a hex value). The text color follows the background so it stays readable, or you can choose a text color for the sticky. Words inside the sticky can be colored with the formatting toolbar.
  • Collapse a sticky to its header, or keep it on top of other windows where your desktop allows it.
  • Closing a sticky (Ctrl+W or the × in the corner) only hides it; the note stays. Find all stickies on the Stickies page.

Reminders

  • Add a reminder from a note (the note menu's Add reminder… or /reminder).
  • Suggestions: type a phrase such as “tomorrow at 5”, “in 2 hours” or “submit this by tomorrow end of the day”. Infinity Notes shows the date and time and asks you to confirm; nothing is created on its own. Suggestions understand English only, and ambiguous dates such as “03/04” ask you to pick.
  • Reminders have a time zone, also shown in your own time, and can repeat and follow up. Quiet hours hold notifications back.
  • The Reminders page and the small reminder widget (View > Show reminder widget) show what is due. Done completes a reminder, Snooze moves it.

When reminders arrive

Reminders are delivered only while Infinity Notes is running, including when only a sticky, the widget or the tray icon is open. When the app is fully quit, nothing is delivered; at the next start you see a summary of what you missed. To keep reminders coming, set When the main window closes to Keep running in Settings > Windows and tray and, if you like, turn on Start Infinity Notes when you sign in.

Search and links

  • Ctrl+K searches note titles and text and runs commands. Filters narrow it to a project or to tags.
  • Ctrl+F finds text inside the open note or sticky.
  • Link to another note, or to a single paragraph, with /link or the note menu's Link to note…. Ctrl+click opens a link.
  • The details panel lists the links into and out of the open note.
  • Search does not look inside locked notes.

Backup and restore

  • Back up: File > Back up now… writes one .infinitybackup file with every note, copied file, reminder and setting, checked with SHA-256 hashes. It is safe to do while you work.
  • Automatic backups: Settings > Backup can write a backup every 1, 7, 14 or 30 days to a folder you choose, keeping the newest 3 to 20.
  • Restore: File > Restore from backup… checks the whole file first, then restarts and swaps it in. Your previous data is kept as a copy until you delete it in Settings > Backup; if anything goes wrong, it is put back.
  • Move notes to another computer: File > Export all notes… writes an .infinityexport file; File > Import notes… adds its notes as copies and never overwrites existing notes.
  • One note as a document: File > Export note as Markdown… or Export note as plain text…. Markdown export leaves out reminders, tags, colors and fonts.

Keep backups on another disk or computer.

Where your data lives

All your notes, copied files, reminders and settings are in one folder. The logs are in its logs folder.

System Folder
Windows %APPDATA%\Infinity Notes
Linux ~/.config/Infinity Notes

Back up with File > Back up now… rather than copying the folder while the app runs.

Update and uninstall

Windows

To update, run a newer installer over the installed app. To uninstall, use Settings > Apps > Installed apps > Infinity Notes > Uninstall. This removes the program, its shortcuts and its uninstall entry; your notes are kept in %APPDATA%\Infinity Notes. Delete that folder yourself if you want them gone.

Linux

Update by installing the newer .deb the same way. Remove the app with sudo apt remove infinity-notes, or delete the AppImage file. Your notes in ~/.config/Infinity Notes are kept.

Getting help

  • If the app cannot start, a startup screen explains why. The logs are in the logs folder inside your data folder; they hold diagnostic text, but read them before you attach them anywhere.
  • On Wayland desktops the window manager decides window positions and whether a window stays on top; Infinity Notes keeps window sizes.
  • Questions and bug reports: GitHub Issues. Changes per version: the changelog.
