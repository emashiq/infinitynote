How to use Infinity Notes

A practical walkthrough. Everything you write stays on your computer: there is no account, no sync and no network service.

Getting started

  1. Download the installer for your system and install it.
  2. Start Infinity Notes. There is nothing to sign in to. Home shows quick actions, pinned notes, recent notes and the reminders due today.
  3. Press Ctrl+N, type a title in the new tab, press Enter and keep typing the text. Notes save on their own as you write.

The window

  • Top bar: the menus File, View and Help, the search box in the middle (Ctrl+K), buttons that show or hide the notes tree and the details panel, and the window buttons. Alt opens the menus from the keyboard.
  • Rail on the left: Home, Notes, Stickies, Reminders, Graph, and Settings at the bottom.
  • Notes tree: Common, your projects and their folders with their notes and documents, and the Trash. Toggle it with Ctrl+\.
  • Details panel: for a note, its info, the Outline of its headings, Comments, reminders, links in and out and the Local graph; for a document, its info, the notes that link to it, comments and the local graph. Toggle it with Ctrl+Shift+\. Under a note's text you see its word count and reading time.
  • Theme: View > Light, Dark or System theme.

Notes and projects

  • Notes live in Common or in a project, inside folders as deep as you like. Create them from the tree, from Home, or with Ctrl+N.
  • In the tree, arrow keys move, expand and collapse, Enter opens, F2 renames, Delete moves to the Trash and Shift+F10 opens the item menu.
  • Documents sit in the same tree, next to your notes; see Documents.
  • Deleted notes and documents go to the Trash, where you can restore them.
  • Every note keeps a version history (right-click the text > Version history) so you can go back to an earlier state.
  • A note is rich text or plain text, and can be converted either way from the note menu.

Tabs

Each note opens in its own tab; the tab is the note's title. Double-click a tab, or press F2 on it, to rename the note. Switch with Ctrl+Tab and Ctrl+Shift+Tab, close with Ctrl+W. Your tabs come back when you start the app again.

Formatting

  • Toolbar: select text and a small toolbar appears above it (Alt+F10 shows it at the cursor). It has bold, italic, links and more, plus Font, Size, Text color and Highlight.
  • Colors: pick a preset or Default, which removes the color so the text follows the light or dark theme.
  • Insert menu: type / at the start of a line or after a space for headings, lists, checklists, quotes, code, diagrams, math, tables, images, files, links and reminders.
  • Note menu: right-click the text (or Shift+F10) for insert, reminders, Find, Convert, Version history, Lock note and Float as sticky.
  • Images: paste, drop or insert them.

Markdown and plain-text export keep the text and structure but drop fonts, sizes and colors.

Tables

  • Insert a table from the / menu or the note menu: choose the number of rows and columns and whether the first row is a header.
  • Tab and Shift+Tab move between cells. Drag a column border to resize it.
  • The Table menu adds and removes rows and columns, turns the header row on or off, and deletes the table.
  • Cells take the same formatting as the rest of the note, including fonts and colors.
  • Copy and paste work both ways: copy cells into a spreadsheet, or paste a table from a spreadsheet or a web page (or tab-separated text) to create one.

Markdown export writes tables as Markdown tables. A table can have up to 10,000 cells, and a merged cell can span up to 50 rows or columns. A larger table is refused with a message, and tab-separated text that would make one is pasted as plain text.

Code, diagrams and math

  • Code: /code or three backticks make a code block. Pick its language and the code is colored.
  • Diagrams: /diagram inserts a Mermaid diagram (flowcharts, sequence diagrams, Gantt charts and more), in notes and stickies. Edit shows the source with the drawing below it, Preview the drawing only; a mistake in the source is explained under it. Copy as SVG and Copy as PNG put the drawing on the clipboard. Diagrams follow the light or dark theme.
  • Math: type $x^2$ after a space for a formula in the text, or $$ and a space at the start of a line (or /math) for a formula on its own line. Click a formula to edit its TeX; Enter (in a block Ctrl+Enter) keeps it, Escape cancels.

Very long diagrams (over 20,000 characters) are not drawn.

Files

Add a file to a note by dropping or pasting it, or from the / menu. Images are always copied. For other files Infinity Notes asks how to keep them:

  • Copy into Infinity Notes: a copy goes into your data folder. It stays available if the original is moved or deleted, and it is included in your backups.
  • Link to the original: the note points at the file where it is. Nothing is copied, so it is not in your backups, and the link stops working if you move, rename or delete the original.

Under When adding files in Settings you can choose Ask every time (the default), Always copy into Infinity Notes or Always link to the original. A linked file can be copied in later with Copy into Infinity Notes on its chip.

Files over 25 MB are never copied. Infinity Notes shows a warning and offers only a link to the original. You can lower this copy limit in Settings.

On Windows only files on a local drive can be linked. Copy files from a network location into Infinity Notes instead; network links in an imported export are not kept.

Documents

PDF, Word (.docx), PowerPoint (.pptx), Excel (.xlsx), CSV and HTML files live in Common, projects and folders next to your notes. They open in tabs, can be moved, favorited, trashed and restored, appear on Home, and their text is found by search.

  • Add a file: Import file… in the File menu, Home, Ctrl+K or the tree's right-click menu. Like any file, it is copied into Infinity Notes or linked to the original (see Files). On a PDF or Office file attached to a note, choose Open in Infinity Notes.
  • Start a blank one: New Word document, New spreadsheet or New presentation in the File menu, the command palette or the tree's right-click menu.
  • Saving: edits stay in the tab until you Save (Ctrl+S); the toolbar says Unsaved changes until then, and leaving the tab, closing it or quitting saves first. Each save keeps the previous version (see Document versions).
  • Linked documents are saved back to the original file, safely, and Infinity Notes warns you if that file changed on disk since you opened it.
  • Macros never run: macro-enabled files (.xlsm, .docm, .pptm) are not opened; use your system app for them.

Documents cannot be locked, and cannot be printed from the app yet: use Export a copy… and print it from another program.

PDF documents

  • Reading: pages scroll continuously. The toolbar has the page number (type one and press Enter), zoom (Fit width, Fit page, 50–400 %) and Rotate view, which does not change the file. Pages and outline shows thumbnails and the PDF's bookmarks. Select text and copy it with Ctrl+C.
  • Find: Ctrl+F highlights matches as you type; Enter and Shift+Enter go to the next and previous one.
  • Annotating: Highlight, Add text, Draw and Add image, with a color button. Click a mark to select it; Delete removes it. Annotations are saved into the PDF as standard annotations, so other PDF readers show them.
  • Pages: select thumbnails, then use the Pages menu to rotate, move (or drag them, or Alt+Up/Down), insert a blank page, insert the pages of another PDF, extract them to a new PDF, or delete them.
  • Password-protected PDFs ask for the password, which is used to open the file and never stored. Their pages cannot be rearranged, and their text is not added to search.
  • PDF forms can be filled in and saved; PDF scripts never run.

Spreadsheets

  • Editing: click a cell and type; start with = for a formula. The toolbar has number formats, fonts, colors, borders, merge, alignment, wrap, freeze panes, filter and sort, cell notes and quick sums. Right-click a cell or header to insert, delete, hide or resize rows and columns.
  • Sheets: the tabs at the bottom add, rename, copy, delete, color, hide and reorder sheets.
  • Copy and paste: Ctrl+C copies cells into Excel, LibreOffice or a note's table; Ctrl+V pastes tables from spreadsheets or web pages, or tab-separated text.
  • What is kept: values, formulas, formatting, merges, sizes, hidden rows and columns, frozen panes, filters, notes and sheet colors. Parts the editor cannot keep (charts, pivot tables, pictures, conditional formatting and similar) are listed before the first save, with Save without them or Cancel. To keep them, use Open in system app.
  • CSV files keep values only, and keep their separator, text encoding and line endings.
  • Files up to 25 MB, 64 sheets and 500,000 filled cells open in the editor; larger ones open in your system app.

Word documents

  • Word documents (.docx) open as pages. The toolbar has styles, font and size, bold, italic, underline, colors, alignment, spacing, lists, tables, pictures, links and comments. Page break (Ctrl+Enter) starts a new page.
  • The document's comments show beside the page: reply, resolve, or add your own (right-click selected text, Add comment). They are written into the file under the name “Infinity Notes”.
  • Saving writes your edits into the file and keeps everything else in it exactly as it was, so it still opens in Word and LibreOffice.
  • A file with content Infinity Notes cannot write back unchanged opens as a read-only preview that says why; edit it in your system app.

Presentations

  • PowerPoint files (.pptx) open with the slides on the left, the slide in the middle and its Speaker notes below.
  • Slides: New slide, Duplicate slide (Ctrl+D) and Delete slide; drag a slide or press Alt+Up/Down to move it.
  • Shapes: click to select, drag to move, drag the handles to resize. Double-click a text box (or press Enter) to edit its text. Bold, italic, underline, size and color format the selected text. Text box and Picture add new ones.
  • Present (F5) shows the slides over the whole window; arrow keys, Space and a click step through them, Escape ends the show.
  • Saving changes only the slides you changed and keeps the rest of the file exactly as it was.

Charts, SmartArt and animations are shown simplified or not at all, but kept in the file. Fonts, alignment and bullets are kept but cannot be changed yet, and presentation mode does not show speaker notes.

Web pages

A saved web page (.html) opens read-only in its own tab, as it was saved, but nothing in it runs: no scripts, no forms, and nothing is loaded from the internet. Links in the page do not open; Links lists its web links to copy, and Source shows its markup as text.

Document versions

PDF, Word, PowerPoint, Excel and CSV tabs have Versions in their header, listing each earlier version with its time and size.

  • Open shows a version read-only.
  • Restore makes it the current version again; the version it replaces is kept.
  • Save as copy adds it as a new document next to this one.
  • Export a copy… writes the saved file, or the version you are viewing, anywhere you choose.

Locked notes

Lock a note that holds something private with Lock note… in the note menu, the Details panel or the command palette. Its body is encrypted on disk (AES-256-GCM). The title and any reminder titles are not encrypted and stay visible, so you can still find the note in the tree, tabs and search; search never looks inside the body.

  • A password is always required, on Windows and Linux.
  • On Windows computers where it is available you can also unlock with Windows Hello (face, fingerprint or PIN). The password stays the fallback, so a Windows reinstall never locks you out.
  • An unlocked note locks itself again after 5 idle minutes (change this in Settings), when you lock the screen (Windows) or the computer sleeps, and when you quit. Use Lock now or Lock all notes to lock at once.
  • New locked note… and New locked sticky… (File menu, command palette, Home, the tree's right-click menu and the Stickies page) ask for the password first, so the text is never stored unencrypted, not even as a first save.
  • Comments on a locked note are encrypted with it. Reminders in it notify without showing their text, and Export all notes leaves locked notes out. Backups contain them encrypted.
  • A locked note can float as a sticky; see Locked stickies.

Locking cannot be taken back for what was saved before. When you lock a note, its earlier versions, drafts, search entries and other unencrypted copies are destroyed, so version history cannot bring back an unlocked copy. Backups you made before locking still contain the old text. A forgotten password cannot be recovered: there is no reset and no way to read the note without it. Keep the password somewhere safe.

Attached and linked files are not encrypted. Keep confidential files out of locked notes or protect them separately.

Stickies

  • Right-click a note's text and choose Float as sticky, or press Ctrl+Shift+N for a new one. The sticky is its own small window outside the main window.
  • Type in the sticky or in the note's tab: both show the same note as you write.
  • Drag a sticky by its header. Click its title (or press F2) to rename it. The header also shows the note's project.
  • Colors: pick one of the presets or a custom color (any color, with a color picker or a hex value). The text color follows the background so it stays readable, or you can choose a text color for the sticky. Words inside the sticky can be colored with the formatting toolbar.
  • Collapse a sticky to its header, or keep it on top of other windows where your desktop allows it.
  • Closing a sticky (Ctrl+W or the × in the corner) only hides it; the note stays. Find all stickies on the Stickies page.

Locked stickies

A locked note can float as a sticky, and locking a floating sticky keeps it floating. A locked sticky shows its title and color and a blurred panel instead of the text: the text is not in the window at all until you show it.

  • Show it with its PIN, the password or Windows Hello (where it is set up for the note).
  • The PIN (4 to 8 digits) is set when you lock or create the sticky, from its menu (Set PIN…) or in Lock settings…. It is a quick way to show the sticky again while the note is unlocked for the session. After a restart or when the note has locked again, the password or Windows Hello is needed.
  • It blurs again 1 minute after you last type, click, scroll or point at it (30 seconds to 5 minutes under Blur locked stickies after in Settings), at once with Blur now, and on screen lock, sleep or Lock now. What you typed is saved, encrypted, first.
  • The Stickies page lists a locked sticky with a lock and never shows its text.

The PIN does not protect your files; the password does. After five wrong PINs in a row only the password or Windows Hello shows the sticky.

Reminders

  • Add a reminder from a note (the note menu's Add reminder… or /reminder).
  • Suggestions: type a phrase such as “tomorrow at 5”, “in 2 hours” or “submit this by tomorrow end of the day”. Infinity Notes shows the date and time and asks you to confirm; nothing is created on its own. Suggestions understand English only, and ambiguous dates such as “03/04” ask you to pick.
  • Reminders have a time zone, also shown in your own time, and can repeat and follow up. Quiet hours hold notifications back.
  • The Reminders page and the small reminder widget (View > Show reminder widget) show what is due. Done completes a reminder, Snooze moves it.

When reminders arrive

Reminders are delivered only while Infinity Notes is running, including when only a sticky, the widget or the tray icon is open. When the app is fully quit, nothing is delivered; at the next start you see a summary of what you missed. To keep reminders coming, set When the main window closes to Keep running in Settings > Windows and tray and, if you like, turn on Start Infinity Notes when you sign in.

Search and links

  • Ctrl+K searches note titles and text, documents and their text, and comments, and runs commands. Filters narrow it to a project or to tags.
  • Ctrl+F finds text inside the open note, sticky or document.
  • Link: type [[ (or press Ctrl+Shift+L, or use /link) and pick a note or document by its title; the list matches loosely, so “mtg” finds “Meeting”. Link a whole note, a paragraph or heading, a whole document, or a place in it: a PDF page, a slide, a sheet or cell (Budget!B2) or a Word heading.
  • Create note “…” in that list makes a new note with the typed title. Select text and press Ctrl+Shift+K to turn it into a link that keeps your text. Click a link to open it.
  • Renaming or moving the target keeps its links. The details panel lists the links into and out of the open note, and the notes that link to a document.
  • Search does not look inside locked notes.

Comments

  • On a note: select text (also inside a table cell) and choose Comment in the formatting toolbar or press Ctrl+Alt+M. Type the comment in the details panel; Ctrl+Enter saves it. The commented text is highlighted. Comments need a rich-text note.
  • Threads: Reply, Edit, Resolve and Reopen, Delete a reply or Delete thread. Click a thread to jump to its text; if the text was deleted it shows Text removed.
  • On documents: select text on a PDF page (or comment on the page shown), a spreadsheet cell, a slide or shape, a Word paragraph, or text in a web page's Source view. Clicking the thread opens the document at that place.
  • Comments go to the Trash and come back with their note or document. Backups keep them; Markdown, HTML and PDF exports of a note do not.

Comments on PDFs, spreadsheets, presentations and web pages are kept in Infinity Notes, not written into the files. Comments on locked notes are encrypted with the note.

Graph

The Graph (the rail button, Open graph in the command palette, or on Common, a project or a folder in the tree) shows your notes and documents as dots and the links between them as lines. Notes are circles, documents are squares colored by type, and items with more links are bigger. A locked note shows only its title.

  • Show picks everything, Common, a project or a folder; Notes, Documents, Tag and Unlinked items filter it.
  • Scroll or press + and - to zoom, drag the background or use the arrow keys to move, and press 0 to fit. Click a dot to open the item.
  • Search titles highlights matching items and dims the rest.
  • List shows every item with what it is linked with, for the keyboard and screen readers.
  • Each note and document has a Local graph in the details panel: what is 1, 2 or 3 links away.

Backup and restore

  • Back up: File > Back up now… writes one .infinitybackup file with every note, copied file and document, comment, reminder and setting, checked with SHA-256 hashes. It is safe to do while you work.
  • Automatic backups: Settings > Backup can write a backup every 1, 7, 14 or 30 days to a folder you choose, keeping the newest 3 to 20.
  • Restore: File > Restore from backup… checks the whole file first, then restarts and swaps it in. Your previous data is kept as a copy until you delete it in Settings > Backup; if anything goes wrong, it is put back.
  • Move notes to another computer: File > Export all notes… writes an .infinityexport file; File > Import notes… adds its notes as copies and never overwrites existing notes.
  • One note as a document: File > Export note as Markdown… or Export note as plain text…. Markdown export leaves out reminders, tags, colors and fonts.
  • Export or print a note: File > Export note as HTML… or Export note as PDF… writes one file with the note's text, images, diagrams and formulas; Print note… opens the system print dialog. Nothing is loaded from the internet, links are shown as plain text, and a locked note must be unlocked first.
  • A document: Export a copy… in its tab writes the file anywhere you choose.

Keep backups on another disk or computer.

Where your data lives

All your notes, documents, copied files, comments, reminders and settings are in one folder. The logs are in its logs folder.

System Folder
Windows %APPDATA%\Infinity Notes
Linux ~/.config/Infinity Notes

Back up with File > Back up now… rather than copying the folder while the app runs.

Update and uninstall

Windows

To update, run a newer installer over the installed app. To uninstall, use Settings > Apps > Installed apps > Infinity Notes > Uninstall. This removes the program, its shortcuts and its uninstall entry; your notes are kept in %APPDATA%\Infinity Notes. Delete that folder yourself if you want them gone.

Linux

Update by installing the newer .deb the same way. Remove the app with sudo apt remove infinity-notes, or delete the AppImage file. Your notes in ~/.config/Infinity Notes are kept.

Getting help

  • If the app cannot start, a startup screen explains why. The logs are in the logs folder inside your data folder; they hold diagnostic text, but read them before you attach them anywhere.
  • On Wayland desktops the window manager decides window positions and whether a window stays on top; Infinity Notes keeps window sizes.
  • Questions and bug reports: GitHub Issues. Changes per version: the changelog.
  • Every component Infinity Notes includes is free and open source and free for any use, commercial included. Their licenses are in THIRD_PARTY_NOTICES.md, which also ships with every release.
