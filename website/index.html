Check your download. Every release ships a SHA256SUMS.txt. Compare it with Get-FileHash .\Infinity-Notes-Setup-x64.exe on Windows or sha256sum infinity-notes_amd64.deb on Linux before you run anything. Older versions and release notes: all releases.

Install

A minute or two on either system. Your notes are kept when you update or uninstall.

Windows

  1. Download Infinity-Notes-Setup-x64.exe and run it.
  2. SmartScreen says “Windows protected your PC”: click More info, then Run anyway. This appears because the installer is not signed.
  3. The installer sets Infinity Notes up for your user only, so no administrator rights are needed. You can change the folder.
  4. Start Infinity Notes from the Start menu or the desktop shortcut.

Update: run a newer installer over the installed app. Uninstall: Settings > Apps > Installed apps > Infinity Notes. Your notes stay in %APPDATA%\Infinity Notes until you delete that folder yourself.

Linux

Debian or Ubuntu package (recommended):

sudo apt install ./infinity-notes_amd64.deb
infinity-notes    # or use the app menu

AppImage, other distributions:

chmod +x Infinity-Notes-x86_64.AppImage
./Infinity-Notes-x86_64.AppImage

The AppImage needs FUSE 2 (sudo apt install libfuse2t64 on Ubuntu 24.04 and newer).

Infinity Notes always runs inside Chromium's sandbox. Ubuntu 24.04 and newer restrict the user namespaces it uses; the .deb installs an AppArmor profile that allows them, the AppImage cannot, so it may refuse to start there. Never start the app with --no-sandbox. Uninstall: sudo apt remove infinity-notes; your notes in ~/.config/Infinity Notes stay.

Your first note

Infinity Notes opens ready to go. There is nothing to sign in to.

  1. Create a note Press Ctrl N, type a title, press Enter and keep writing.
  2. Format it Select text for the toolbar, or type / for headings, lists, tables and files.
  3. Float it Right-click the text and choose Float as sticky to keep it on your desktop.
  4. Get reminded Type “tomorrow at 5” and confirm the suggested reminder, or add one from the note menu.

What it does

Everything runs locally. No cloud, no sync, no sharing links.

Notes and projects

Rich or plain-text notes in Common or in projects with folders of any depth. Tabs, autosave, version history and a Trash you can restore from.

Formatting and tables

Headings, lists, checklists, fonts, sizes, text colors and highlights. Tables copy and paste to and from spreadsheets.

Files in your notes

Copy a file into Infinity Notes so it travels with your backups, or just link to the original where it is.

Locked notes

Lock a note with a password, and unlock it with Windows Hello too where available. Its body is encrypted on disk, and earlier unencrypted copies are destroyed.

Floating stickies

Any note in its own small window, editable there and in the main window at once. Any color you like, colored text, collapse and keep on top.

Time-zone reminders

Reminders in any time zone with repeats and follow-ups, suggested from what you type and created only when you confirm. A small widget shows what is due.

Links and search

Link notes and single paragraphs, see what links back, and find anything with Ctrl+K.

Backup and restore

Everything in one verified backup file, by hand or on a schedule. Restore keeps your previous data. Export, import and Markdown export too.

A closer look

Light and dark themes follow your system.

Good to know

What Infinity Notes does not do, so nothing surprises you.

Private by design

  • No accounts, no sync, no telemetry and no network access.
  • Your notes, files, stickies and reminders live in one data folder on your computer; backups are files you own.
  • Uninstalling never deletes your data folder.

Known limits

  • Reminders arrive while the app runs, also in the background with only a sticky, the widget or the tray icon open. A fully quit app delivers nothing and shows what you missed at the next start.
  • On Wayland desktops the window manager decides window positions and always on top; sizes are kept.
  • Reminder suggestions understand English only.
  • Markdown export leaves out reminders, tags, colors and fonts.
  • A forgotten password for a locked note cannot be recovered.
