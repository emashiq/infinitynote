# Native OS matrix

Every native case of `infinity-notes-claude-pack/TEST_MATRIX.md` ("Native OS matrix") and the native parts of BACKLOG rows, with the host it ran on, the date, the status and the evidence. Documentation is not evidence that a test ran: every `pass` names a log.

Statuses:

- `pass`: ran on the named host and met the expectation.
- `pass (fallback)`: the native feature does not exist on the host (for example, no notification server under WSLg); the documented capability fallback ran and meets the user flow.
- `fail`: ran and did not meet the expectation.
- `not_run`: needs a real person, real pointer or keyboard input, real hardware events or a desktop this run did not have. Exact manual steps are given in section 5.
- `outside_validation_scope`: GNOME- or X11-only cases. The user selected WSL2 + WSLg as the Linux validation environment (CLAUDE.md, 2026-10-08); WSLg results are never labelled GNOME.

Log paths are relative to `.infinity-work/logs/phase-09/` unless they start with `.infinity-work/`.

### 3a. WSLg real-pointer run, 2026-10-09

- Host: WIN with WSLG (section 1). WSLg 1.0.73, Weston 2318feca, FreeRDP c4030980; Electron on XWayland (ozone `x11`) under Weston. This is not GNOME (`final2-wsl-env.log`).
- Build: the final `.deb` (SHA-256 `b52aa1d3…ecbf4`), installed with `wsl -d Ubuntu -u root -- dpkg -i`. It was started as `infinity` with `INFINITY_NOTES_USER_DATA_DIR=/tmp/infinity-wslg-native` and without `--no-sandbox` (`native-wslg/launch-run1.log`, `launch-run2.log`, both exit 0 after File > Quit).
- Method: WSLg shows each app window on the Windows desktop as an `msrdc.exe` `RAIL_WINDOW`. Orca does not list these windows. Real OS pointer input went through Win32 `SetCursorPos` and `mouse_event` (DPI-aware). ## 5. Manual steps for the native cases

M1-M6, M10 and M13 passed in the native GUI run of 2026-10-09 (section 2a), and the WSLg move and resize passed (section 3a). M7, M9, M11 and M12 are still `not_run` and required; M8 is recommended. FINAL_REPORT section 8 gives the full step lists. On a development machine, first check that no other Start menu shortcut carries the AUMID `com.infinitynotes.desktop` (N-D1). Use the installed build (`npm run package:current`, then run the installer). Record the date, the Windows build, pass or fail and a screenshot path in section 2. Uninstall afterwards (Settings > Apps) unless more cases follow.

- **M1 Toast click.** Create a note "Click test" with the paragraph "Open me"; put the cursor in it; More > Add reminder… two minutes ahead; Save. Close the main window and choose Keep running. Click the toast when it appears. Expected: the main window returns with "Click test" active and "Open me" selected and highlighted.
- **M2 Action Center click (A05-F2).** Repeat M1, but let the toast time out (about 5 s); open Action Center (Win+N) and click the notification there. Expected: as M1.
- **M3 Tray.** Close the main window with Keep running. Click the tray icon: the main window returns. Right-click: Open, New sticky, Show widget, Quit. Quit: the process exits (Task Manager shows no Infinity Notes).
- **M4 Drag and resize.** Float two notes and show the widget. Drag each by its header (for a sticky: the scope badge or the gaps, not the title field) to another place, resize from the edges, quit and start again: positions and sizes are restored; a sticky dragged half off-screen comes back fully visible after a restart.
- **M5 Title bar.** Use minimize, maximize/restore and close in the main window's caption with the mouse; drag the window by the empty title area; double-click it to maximize.
- **M6 Always on top.** Pin a sticky and the widget; click another application's window over them: both stay on top. Unpin: they go behind.
- **M7 Sleep and wake.** Create a reminder due in 3 minutes, put the PC to sleep for 5 minutes, wake it. Expected: one alert (or an overdue summary when more than 3), no burst.
- **M8 Time-zone change.** Create a reminder in the computer's zone; change Windows' time zone in Settings > Time & language while the app runs. Expected: the Reminders page shows the same instant in the new zone; a reminder pinned to another zone keeps its wall time there.
- **M9 Launch at login.** Settings > Windows and tray > Start Infinity Notes when you sign in: on. Sign out and in: the app starts in the background (tray). Turn it off and confirm the entry is gone from Task Manager > Startup apps.
- **M10 Global shortcut.** Settings > Keyboard: turn on the quick-sticky shortcut (Ctrl+Alt+N). With another application focused, press it: a new sticky opens.
- **M11 Scaling.** Set display scaling to 125 %, 150 % and 200 %; check that text, icons and the title-bar buttons are crisp and that stickies keep their size.
- **M12 Second monitor.** Drag a sticky to the second display, quit, start: it returns there. Quit, disconnect that display, start: the sticky appears fully on the remaining display.
- **M13 File hand-off.** Attach a PDF to a note; Open opens it in the default viewer; Show in folder opens Explorer with it selected.
